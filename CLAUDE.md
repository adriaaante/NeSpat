# NeSpat

## Что это
Сайт спортивного клуба уличных тренировок «НЕ СПАТЬ МОСКВА» (nespat).
Статический лендинг: HTML + CSS + vanilla JS, без сборки и зависимостей.
Фирменный стиль: чёрный/белый/красный (#e02b2b), шрифты Oswald + Inter.
**Шрифты хостятся локально** (`assets/fonts/{oswald,inter}-{latin,cyrillic}.woff2`,
вариативные 400–700, вместе 96 КБ) — Google Fonts не подключается: в РФ он
работает нестабильно, и при недоступности сайт терял гарнитуру. Подключение —
`@font-face` в начале `style.css` + preload в `<head>`; у `404.html` стили
инлайновые, там свой блок `@font-face` (правки шрифтов нужно дублировать).

## Структура проекта

  галерея, 7 званий, форма записи). SVG-иконки — спрайт в конце файла.
- `assets/css/style.css` — все стили (дизайн-токены в `:root`).
- `assets/js/main.js` — навигация, reveal-анимации, параллакс, лайтбокс,
  маска телефона, отправка формы в Telegram.
- `assets/js/config.js` — токен/chat_id Telegram-бота (см. «Форма заявок»).
- `assets/img/` — фото с тренировок (из HEIC через thumbnail-API Google Drive;
  пережаты: длинная сторона ≤1800, JPEG q82 progressive, 19→8.7 МБ.
  `atmosphere-0*.png` стали `.jpg` — альфа была артефактом конвертации,
  подложен фон сайта #0a0a0b), `logo.jpg` (лого на чёрном фоне,
  на сайте применяется mix-blend-mode: screen), постеры видео,
  `monogram.png` (монограмма НСМ, вырезана из logo.jpg, белая на прозрачном —
  шапка/подвал), `favicon.png` (монограмма на тёмном квадрате). Самодельный
  щит «НС» использовать нельзя — просили убрать; только официальная графика.
- `assets/video/` — вертикальные видео: `reel-*.mp4` (720p, полные, со звуком,
  для лайтбокса; h264 crf31 + aac 80k) и `loop-*.mp4` (480p, 7 с, без звука,
  crf32, автоплей-превью в галерее). Все с `+faststart` — начинают играть
  до полной загрузки. Итого 29→18 МБ; на глаз от оригинала не отличаются
  (сравнивал кадры), сильнее жать не стоит.
- `certificate.html` — просмотр сертификата по ссылке + форма проверки
  подлинности (открывается без хэша). `certificate-studio.html` — бывшая
  студия выдачи, с 26.10.2026 уводит в штаб клуба (`crm/`). Обе страницы `noindex`, в sitemap НЕ добавлять.
- `assets/js/cert-core.js` — звания, SHA-256/HMAC на чистом JS, номер, подпись,
  кодирование ссылки. `cert-render.js` — бланк и 7 эмблем. `qr.js` — свой
  генератор QR. `assets/css/certificate.css` — бланк + печать A4.
- `certificate-guide.html` — руководство по выдаче со скриншотами
  (`assets/img/guide/`); из него же печатается PDF
  `assets/doc/nespat-certificates-guide.pdf`. Ссылки на руководство — в шапке
  студии и блоком под формой.
- `.claude/skills/` — 7 скиллов пакета UI/UX Pro Max v2.11.0 (апстрим,
  руками не редактировать; обновлять целиком из релиза).
- `zapis.html` — публичная запись на мероприятия (см. «Штаб клуба»).
- `404.html` — страница ошибки в фирменной палитре (подключена через
  `ErrorDocument` в `.htaccess`); `robots.txt`, `sitemap.xml` — для поиска.

## Деплой
- **Боевой хостинг — Beget** (аккаунт `dudareid`, сервер `dudareid.beget.tech`,
  там же voidaform.ru и подноль.рф). Выкладка автоматическая:
  `.github/workflows/deploy.yml` — push в `claude/install-ui-ux-pro-max-skill-8bfxro`
  (или `main`) → заливка по FTP. Нужны секреты репо `FTP_SERVER`/`FTP_USERNAME`/
  `FTP_PASSWORD`/`FTP_DIR`; без них шаг мягко пропускается (warning, не ошибка).
  На хостинг не едут `.github/`, `.claude/`, `CLAUDE.md`.
- **Три домена, один сайт.** Основной — **nespatmoskva.ru**; `dontsleepmoscow.ru`
  и `неспатьмосква.рф` (punycode `xn--80aafk0alelgtej4k.xn--p1ai`) склеены с ним
  301-м редиректом в `.htaccess` (там же https, без www, кэш, gzip, Accept-Ranges
  для mp4 — иначе не перематывается видео). Canonical/OG/sitemap/robots смотрят
  на nespatmoskva.ru. При смене основного домена править: `.htaccess`,
  `index.html` (canonical, og:url, og:image, JSON-LD), `robots.txt`, `sitemap.xml`.
- Все три домена должны быть привязаны к одному сайту в панели Beget, и на
  каждом выпущен свой SSL Let's Encrypt — иначе редирект с https зеркала
  упрётся в ошибку сертификата раньше, чем сработает.
- GitHub Pages (https://adriaaante.github.io/NeSpat/) остаётся как запасная
  витрина; canonical смотрит на домен, дублем в поиске не станет.

## Форма заявок → Telegram
Заявки (имя + телефон) шлются ботом в группу напрямую из браузера через
Bot API `sendMessage`. Настройка: вписать `telegramBotToken` и
`telegramChatId` (у групп отрицательный) в `assets/js/config.js`.
Пока токен пуст, форма показывает подсказку и открывает
`telegramFallbackUrl`. ВАЖНО: токен в статике публичен — использовать
отдельного бота без прав администратора, только для приёма заявок.

## Сертификаты званий
Бэкенда нет: сертификат целиком лежит в ссылке
`certificate.html#1.<base64url(JSON)>`, JSON `{n:имя, r:звание 1-7, d:дата,
m:комментарий, s:подпись}`. Номер (`k`) в ссылке НЕ хранится — он выводится из
данных, поэтому ссылка короче и QR проще сканируется.
- **Подлинность.** `s` — HMAC-SHA256 (первые 16 hex) от `имя|звание|дата|
  комментарий`; правка любого поля в ссылке ломает подпись. Номер
  `NSM-<звание>-<ГГММ>-<6 знаков>` считается от `имя|звание|год-месяц`, поэтому
  печатный бланк проверяется вручную по номеру + имени. Имя нормализуется
  (регистр, лишние пробелы, ё→е) — «Пётр  Иванов» и «петр иванов» дают один номер.
- **Ключ `CERT_SECRET` в `cert-core.js` менять нельзя** — обнулит подлинность
  всех выданных сертификатов. Ключ виден в исходниках (статика), защита — от
  случайной подделки, не от целенаправленной.
- **Повторная выдача тех же данных даёт тот же номер** — дубликаты не плодятся,
  потерянную ссылку можно собрать заново в студии.
- Пин студии 1234 лежит как `atob('MTIzNA==')`; вход помнится в sessionStorage,
  история выданных — в localStorage `nsm_cert_history` (только этот браузер).
- QR на бланке ведёт на саму ссылку сертификата. Кодировщик свой (байтовый
  режим, уровень M, версии 1–20); сверен помодульно с python-библиотекой
  `qrcode` — 43/43 совпадений, включая выбор маски.
- Печать: `@page A4 landscape`, размеры внутри бланка в `cqw` (масштабируется
  под экран и под лист). Градиентный текст (`background-clip:text`) в печати
  даёт полосы — заголовок принудительно сплошным цветом в `@media print`.
- **Пересобрать PDF руководства** после правок `certificate-guide.html` или
  скриншотов: `node scripts/build-guide-pdf.js` (нужен локальный сервер на 8123).
  Грабли печати: `@page{margin:0}` + отступы внутри `.page` (иначе белая рамка);
  grid-контейнеры Chrome не разрывает между страницами (шаги — обычный поток);
  очень высокие снимки ограничены `max-height`, иначе полстраницы пустует.

## Штаб клуба (CRM) — `crm/`, с 26.10.2026
Адрес `nespatmoskva.ru/crm/` (noindex, `Disallow` в robots). PHP + SQLite без сборки, по образцу
CRM подноль.рф (`adriaaante/demontazhnye_raboty`, `crm/`), но в стиле клуба: тёмный, красный, Oswald/Inter.
**Подписи студии нет и не добавлять** (см. «Грабли»).
- `crm/api.php` — все действия команды (`?a=…`), `crm/pub.php` — публичная запись без входа,
  `crm/lib/` (db, auth; закрыт `.htaccess`), `crm/index.html` + `app.js` + `app.css` (SPA, экраны по `#/…`).
  Меняешь `app.js`/`app.css` — подними `?v=N` в `crm/index.html`.
- **PHP сайта — 8.5** (до 26.10.2026 стояла 5.6, на ней CRM не работает). Версия меняется в панели Beget
  или API `domain/changePhpVersion` для каждого домена отдельно.
- **База** — `crm-data/crm.sqlite` над public_html (`dirname(__DIR__,3)`), не в git и не в FTP; запасной
  путь `crm/data/`. `?a=ping` показывает `store: outside|fallback`. Схема — `crm_migrate()`, версия в
  `PRAGMA user_version`: новое поле → новый блок `if ($v < N)`.
- **Роли в стиле клуба:** Инженер (`dev`) — всё; это учётка разработчика (Adrian), она одна: в «Команде» роль не выбирается, API `user_create` её отклоняет (решение Adrian 27.10.2026); Командир (`head`) — всё, кроме учёток Инженеров;
  Сержант (`manager`) — мероприятия, записи, отметки, участники (без сводки, команды, сертификатов,
  выгрузок и удаления). Права — `crm_can()` в `lib/auth.php`.
- **Человек из команды — тоже участник** (миграция v2, `users.person_id`): при создании телефон обязателен,
  учётка привязывается к карточке участника по номеру (есть — к ней, нет — создаётся, `source=team`); один
  номер — одна активная учётка. Тем, кто создан раньше, — кнопка «Указать телефон» (`?a=user_phone`;
  себе может каждый, другим — кто управляет ролью). В списке команды телефон ведёт на карточку.
- **Вход** — PIN 6 цифр, уникальный, вход сам после 6-й цифры; выданный PIN временный (`must_change`),
  до смены API пускает только к `my_pin`/`me`/`logout`. Подбор: 5 ошибок с IP → 15 мин, 30 за час → час.
  Cookie `nsm_crm` (Path=/crm/, SameSite=Strict), POST только с `X-Requested-With: crm`.
  **Первый Инженер** — `POST ?a=bootstrap` с одноразовым ключом (в коде только его sha256), пока
  пользователей нет. Ключ в репозитории не хранится.
- **Данные:** `people` (участник = телефон `7XXXXXXXXXX`, звание 0–7), `events` (вид, дата, время,
  место, адрес, карта, мест, описание, статус open/closed/cancelled, `code` — для ссылки), `regs`
  (запись: status reg/cancel, came, source site/crm), `certs` (выданные сертификаты), `log` (журнал).
  Мероприятие «прошло» — по московскому времени окончания (нет окончания — начало + 3 ч).
- **Публичная запись** — `zapis.html?e=<code>` (без кода — список ближайших открытых). Имя + телефон +
  согласие (галочка не стоит заранее) → `pub.php?a=register`. Защита: Origin/Referer наших трёх доменов,
  ловушка `company`, подписанный токен (`?a=token`, ≥3 с, ≤6 ч, один раз — `used_tokens`), лимиты
  8/IP за 10 мин и 300 на всех за час. Повторная запись того же телефона — «ты уже записан».
  На экране успеха — `.ics` для календаря. На GitHub Pages PHP нет — страница скажет, что запись недоступна.
- **Звания по посещениям** — `CRM_RANKS` в `lib/db.php`: Боец 10, Железный 30, Страж 100; Новобранец — с
  первого посещения; Защитник, Наставник, Легенда — по решению. «Готов к званию» = набрал посещения на
  следующее. **Сертификат выдаётся только из карточки участника** (решение Adrian 26.10.2026 — там видны
  посещения и путь званий). Раздел «Сертификаты» (`#/certs`, для Командира и Инженера) — реестр всех выданных;
  его кнопка «Выдать сертификат» спрашивает, кому (телефон/имя с подсказкой из базы, нового — добавит),
  и открывает карточку с окном выдачи (`S.openCert`). «+ Участник» на экране участников — завести человека
  вручную (`?a=person_add`). Сертификат из карточки: ссылку собирает тот же `assets/js/cert-core.js`
  (подпись не меняется), запись — в `certs`, звание участника = максимум выданных.
- **Обучение** — при первом входе (`users.tour_done`) — «Обзор штаба» с подсветкой блоков; при первом
  открытии мероприятия/участника — короткая подсказка экрана (флаг в localStorage). Кнопка «?» — **центр
  помощи**: темы по задачам (`TOPICS` в `app.js`: обзор, создать мероприятие, пригласить, отметить пришедших,
  выдать сертификат, найти участника, команда, сводка), сверху — темы текущего экрана. Шаг: `sel` —
  `data-tour="…"` в разметке, `go` — экран, `open` — окно на время шага (form/cert/user, закрывается само,
  ничего не сохраняет), `need` — право роли; тема с `needs: event|person` сама открывает пример.
  Новый блок в интерфейсе → `data-tour` + шаг в нужной теме.
- На телефоне (≤720px) разделы — нижняя панель вкладок, как в приложении. Проверка адаптива: 320/375/414,
  без горизонтальной прокрутки.
- **Старая студия `certificate-studio.html` закрыта 26.10.2026:** на хостинге 301 на `/crm/` (`.htaccess`),
  сам файл — заглушка с переходом (для Pages и закладок). Выданные ею сертификаты действуют — ключ тот же.
  В `certificate-guide.html` сверху плашка «выдача теперь в штабе»; шаги со снимками описывают старую студию.
- Проверять локально: `php -S 127.0.0.1:8099` из корня (cookie без Secure только на 127.0.0.1);
  база при запуске из рабочей копии ляжет в `../crm-data/` над репозиторием.
